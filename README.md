# Traffic Accident Data Analysis

## 📌 Project Overview
Brief description of the traffic accident dataset, goals of the analysis, and key findings.

## 🛠️ Tools & Technologies Used
* **Python (Pandas / Jupyter Notebook)**: Data Cleaning & Preprocessing.
* **Excel**: Initial data exploration & cleaning .
* **Power BI**: Interactive dashboard creation .
* **Tableau**: Visualizations & storytelling .

## 🧹 Data Cleaning Steps
1. Handled missing values and duplicates.
2. Formatted date and time columns.
3. Categorized accident severity and factors.
